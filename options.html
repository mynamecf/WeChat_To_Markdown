配置不同导出模式下的文件名及附件保存路径

导出位置说明 浏览器下载目录

所有文件都保存在 浏览器的默认下载目录 下。扩展读不到这个设置，只能用「最近一次导出的实际落盘位置」反推出来，结果如下（点一下可整段选中复制）：

当前下载目录 尚未导出过，导出一次后这里会显示实际路径

怎么改这个目录？只能去浏览器里改：Chrome「设置 → 下载内容 → 位置」→ 更改。改完再导出一次，上面这行会自动更新。扩展本身没有权限修改它，也不会去改。

扩展无法指定绝对路径（例如直接写到 D:\我的笔记）—— Chrome 下载接口只接受相对于下载目录的路径，加权限也绕不过。想换盘就按上一条改浏览器设置。

只想单独放一个文件夹？在下方「导出的文件夹及 Markdown 名称」前面加前缀即可。例如填写 微信文章/{{date:YYYYMMDD}}_{{title}}， 最终位置：上述目录\微信文章\20261023_文章标题\…

下载到本地配置 推荐 当前使用
当选择“下载到本地”时，会生成文件夹并下载图片附件。
逐篇归档
每篇文章单独一个文件夹，附件随文归档。
平铺归档
所有文章与附件置于同一文件夹，文章平级，附件混排。
路径相对浏览器下载目录。可加子目录前缀，如填 微信文章/{{date:YYYYMMDD}}_{{title}}，最终落在「下载/微信文章/…」。
只允许 {{date}}、{{date:x}}、{{time}}、{{time:x}} 变量，其他变量将被忽略。路径同样相对浏览器下载目录，可加子目录前缀。
支持全部变量。建议包含 {{title}} 或 {{hash8}}，避免多篇文章同名覆盖。
Markdown 中写作（第一张） -
/微信/{{noteFolder}}/ 是从库根起算的绝对路径：{{noteFolder}} 会替换成 .md 所在文件夹（默认 {{date:YYYYMMDD}}_{{title}}），前面的「微信」要按文章文件夹搬进库之后所在的层来填。
